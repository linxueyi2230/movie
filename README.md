# 影帝

**好故事，随时入戏。**

影帝是一款主打免费观影的应用，汇聚电影、电视剧、短剧、综艺、动漫等影视内容。想追新剧、看电影，还是利用碎片时间刷短剧，都可以在这里轻松找到想看的内容。

## 功能特色

- **免费观看**：电影、电视剧、短剧等内容，打开即可探索。
- **发现好片**：通过首页推荐、分类、专题和榜单，发现更多精彩影视。
- **快速搜索**：支持按名称、演员或导演搜索，找片更方便。
- **舒适播放**：支持选集、播放线路切换、倍速和全屏播放。
- **收藏与续看**：收藏喜欢的影片，记录观看进度，下次接着看。
- **下载观看**：支持下载部分影视内容，方便离线观看。
- **个性外观**：支持浅色和深色模式，也可以跟随系统切换。

> 具体影片、播放线路及下载功能以实际提供的内容为准。
